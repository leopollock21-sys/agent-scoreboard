# Security Policy

## Supported Versions

Security fixes are published for the latest supported release series, currently 1.2.x.

## Reporting a Vulnerability

Please report suspected vulnerabilities privately to [Chinlung Technologies](mailto:chinlungtech@gmail.com). Include the affected version, impact, and a concise reproduction. Do not include real score reasons, PINs, API tokens, or other private data in the report.

Please avoid publishing a security issue before a fix is available. We will review reports and coordinate a public fix when practical; no response-time commitment is made.
